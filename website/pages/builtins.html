Built-in functions

Functions that are always available, without any yoink.

Output and input

yap(values...)

Prints the values separated by spaces, then a new line. With no arguments, prints an empty line. Gives back nil.

yap("a", 1, [2], {k: true})

a 1 [2] {k: true}

ask(prompt?)

Prints prompt if given, reads one line of input and gives it back as a string without the trailing new line. Gives nil at the end of input.

Types and conversion

type(x)

The type's name as a string: "num", "str", "bool", "nil", "list", "map" or "fn".

yap(type(1), type("a"), type(nil), type([]), type({}), type(x => x))

num str nil list map fn

num(x)

Converts to a number. Text is parsed (spaces around it are allowed); true and false become 1 and 0. Gives nil if it can't be converted.

int(x)

Like num, then drops the fractional part (towards zero).

str(x)

Converts any value to text, the same way yap would print it.

yap(num(" 2.5 "), num("2.5kg"), int("-7.9"), int(true), str([1, "a"]))

2.5 nil -7 1 [1, "a"]

len(x)

Number of items in a list, entries in a map or bytes in a string. Other values are an error.

Math

FunctionResult
abs(x)Absolute value
floor(x)Round down
ceil(x)Round up
round(x)Round to the nearest whole number (halves round away from zero)
sqrt(x)Square root
pow(a, b)a to the power b, same as a ** b
min(a, b, ...), min(list)Smallest value (numbers or strings)
max(a, b, ...), max(list)Largest value
yap(abs(-3), floor(2.7), ceil(2.1), round(2.5), round(-2.5), sqrt(144), pow(2, 8))
yap(min(4, 2, 9), max([4, 2, 9]), min("pear", "apple"))

3 2 3 3 -3 12 256
2 9 apple

To round to decimal places, scale first: round(x * 100) / 100.

Randomness

FunctionResult
rand()Random number from 0 up to (not including) 1
rand_int(a, b)Random whole number from a to b, including both

Time

FunctionResult
now()Seconds from a fixed point, with high precision. Use differences between two calls to time things.
sleep(seconds)Pause; fractions like 0.1 are fine

Program

FunctionResult
args()List of command-line arguments (strings), not including the program name
exit(code?)Stop now with exit status code (default 0)
vibecheck(cond, msg?)Raise "vibe check failed: msg" if cond is falsy
