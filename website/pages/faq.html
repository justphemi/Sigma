FAQ and limitations

Questions

Why the Gen-Z keywords?

They're short, easy to remember and fun, and each one maps to exactly one idea: fr is if, grind is every loop, cook defines and serve returns. Once you've written one program, you know them.

Is Sigma interpreted?

No. Every program is compiled to C and then to native machine code. The cache makes this feel like a scripting language: you run sig app.sgm and only wait the first time.

Is Sigma ready for production?

It's at version 0.2. It's solid for command-line tools, scripts, data processing, learning and experiments, and it has a test suite. It isn't ready for long-running services (no garbage collector yet), and the language may still change before 1.0.

Do I need to know C?

No. You need a C compiler installed, because Sigma uses it behind the scenes, but you never have to read or write C.

How does it compare to Python, JavaScript or Go?

It feels closest to Python or JavaScript: no types to write, lists and maps built in. It runs much faster than Python, and faster than Node.js on the benchmarks in Performance, while starting up quicker than both. Go and Rust have far bigger ecosystems, concurrency and memory management; Sigma is smaller and simpler.

Can I use C libraries?

Not yet. A way to call C functions is on the roadmap.

Does it work on Windows?

Through WSL (Windows Subsystem for Linux), yes. Native Windows support isn't there yet.

Current limitations

  • No garbage collector. Memory isn't freed until the program exits. Fine for programs that run and finish; not for servers that run for days.
  • Strings are bytes. len, indexing and slice count bytes, so non-English text and symbols take more than one position each. upper and lower only change the letters A to Z.
  • Lambdas copy outer variables. They can't reassign variables from the enclosing scope. Store changing state in a map or list instead.
  • and and or give booleans, not one of their operands, so x or "default" doesn't pick a value.
  • One namespace. All yoinked files share function and global names.
  • A function that reads a top-level variable before the top-level code has assigned it sees nil (or 0 for numbers).
  • No standard library modules yet for JSON, HTTP, dates or regular expressions.
  • macOS and Linux only, and a C compiler is needed to build programs (not to run built ones).

Roadmap

  • Garbage collection
  • Standard library: JSON, HTTP, dates, regular expressions, environment variables
  • Structs or classes with methods
  • Calling C libraries
  • A package manager
  • A language server for editor autocompletion and inline errors

Getting help

Found a bug or have an idea? Open an issue on GitHub. Include the code, what you expected and what happened.
