Sigma

A small, compiled programming language with a friendly syntax. You write it like a scripting language. It runs as fast as C.

Install Sigma Write your first program Learn the language 
cook greet(name) {
    serve "hey {name}, welcome in"
}

squad: ["Ana", "Ben", "Cy"]
grind i, name in squad {
    yap("{i + 1}. {greet(name)}")
}

total: 0
grind n in 1..=1_000_000 { total += n }
yap("sum of the first million numbers: {total}")

1. hey Ana, welcome in
2. hey Ben, welcome in
3. hey Cy, welcome in
sum of the first million numbers: 500000500000

Why Sigma

Fast by default

Sigma compiles to C and then to a native program. Code that works with numbers runs as fast as hand-written C.

No boilerplate

No type annotations, no semicolons, no main function. A program is just the lines you want to run.

Errors that help

Mistakes are caught before your program runs, with the exact line, a pointer to the problem and a hint for fixing it.

One command

sig app.sgm compiles and runs. Unchanged programs start instantly from a cache. sig build makes a standalone executable.

What it looks like

Sigma keeps the familiar ideas from Python and JavaScript and gives them short, memorable names:

SigmaWhat it does
name: "Ada"Create or change a variable
yap(name)Print
fr / nah fr / nahif / else if / else
grindEvery kind of loop
cook and serveDefine a function and return from it
yolo / oops / yeettry / catch / throw
yoink "file.sgm"Use code from another file

The full list is on the syntax reference page.

Good fits

  • Command-line tools and scripts that need to be quick
  • Data crunching: logs, CSV-like text files, word counts, reports
  • Algorithms, puzzles, simulations and games in the terminal
  • Learning to program, with a language that explains its own errors

Sigma is young (version 0.2). It doesn't have a garbage collector yet, so it isn't meant for long-running servers. See FAQ and limitations for the honest list.
