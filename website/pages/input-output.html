Input and output

Talking to the outside world: the terminal, command-line arguments, files, the clock and random numbers.

Printing

yap prints its arguments separated by spaces, followed by a new line.

yap("total:", 42, [1, 2], true)
yap()
yap("done")

total: 42 [1, 2] true

done

To print without spaces between values, build one string with interpolation: yap("{a}{b}").

When output goes to a file or another program (like sig app.sgm > out.txt), Sigma buffers it, which makes printing many lines very fast.

Reading input

ask(prompt) prints the prompt, waits for the user to type a line and gives it back as a string, without the new line. At the end of input (the user pressed Ctrl+D, or a piped file ran out) it gives nil.

-- read every line until the input ends
count: 0
grind {
    line: ask()
    fr line == nil { dip }
    count++
    yap("{count}: {line}")
}

1: first
2: second

That loop also works with piped input, so Sigma programs fit into shell pipelines:

cat names.txt | sig number_lines.sgm

Command-line arguments

args() gives a list of the words typed after the program name:

a: args()
yap(len(a), a)
fr a.has("--verbose") { yap("verbose mode on") }

2 ["report.txt", "--verbose"]
verbose mode on

sig tool.sgm report.txt --verbose

Files

FunctionDoes
read_file(path)The whole file as a string
write_file(path, text)Create or replace the file
append_file(path, text)Add to the end, creating the file if needed
file_exists(path)true or false
write_file("notes.txt", "buy milk\n")
append_file("notes.txt", "call mum\n")
fr file_exists("notes.txt") {
    grind i, line in read_file("notes.txt").trim().split("\n") {
        yap("{i + 1}. {line}")
    }
}

1. buy milk
2. call mum

Paths are relative to the folder you run the program from. A file that can't be read or written raises an error you can catch with yolo.

Line-based data

Simple text formats are easy to read and write: one record per line, fields separated by a character.

write_file("people.csv", "name,age\nAda,36\nTolu,28\n")

people: []
grind line in read_file("people.csv").trim().split("\n").slice(1) {
    f: line.split(",")
    people.push({name: f[0], age: num(f[1])})
}
yap(people)

[{name: "Ada", age: 36}, {name: "Tolu", age: 28}]

Time

now() gives a time in seconds with sub-microsecond precision. It's meant for measuring how long something takes (it's not the date). sleep(seconds) pauses.

start: now()
sleep(0.25)
yap("took {round((now() - start) * 1000)} ms")

Random numbers

yap(rand())            -- a number from 0 up to (not including) 1
yap(rand_int(1, 6))    -- a whole number from 1 to 6, like a die
colors: ["red", "green", "blue"]
yap(colors[rand_int(0, len(colors) - 1)])

Randomness is seeded differently on every run. It's fine for games and simulations, but not for passwords or anything security related.

Ending the program

exit() stops immediately with status 0, and exit(code) with the status you choose. Output printed so far is always flushed first.
