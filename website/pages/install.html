Installation

Sigma installs as a single command called sig. You build it from source, which takes under a minute.

Requirements

  • macOS or Linux. Windows users can use WSL (Windows Subsystem for Linux) and follow the Linux steps.
  • A C and C++ compiler (clang or gcc). Sigma turns your code into C and uses this compiler to make the final program.
  • git, to download the source.

macOS

Install Apple's command line tools, which include clang and git:

xcode-select --install

If it says they're already installed, you're set.

Ubuntu and Debian

sudo apt update
sudo apt install build-essential git

Fedora

sudo dnf install gcc gcc-c++ make git

Arch Linux

sudo pacman -S base-devel git

Build Sigma

git clone https://github.com/justphemi/Sigma.git
cd Sigma
./build.sh

This creates the compiler at build/sig. You can already use it from inside the folder:

./build/sig examples/hello.sgm

Hello, Sigma!

Put sig on your PATH

To run sig from any folder, install it:

./build.sh install

This copies sig to /usr/local/bin. It only asks for your password if that folder needs it. To install somewhere else, set PREFIX:

# installs to ~/.local/bin/sig
PREFIX=~/.local ./build.sh install

If you use a custom prefix, make sure its bin folder is on your PATH. For zsh (the macOS default), add this line to ~/.zshrc; for bash, add it to ~/.bashrc:

export PATH="$HOME/.local/bin:$PATH"

Check that it works

sig version

sigma 0.2.0

Then run the test suite if you like. It compiles and runs a few dozen small programs:

./tests/run.sh

Editor support

The repository includes a VS Code extension in sigma-icons/ with syntax highlighting, comment toggling, bracket matching and a file icon for .sgm files. To install it from the source folder:

cd sigma-icons
npx @vscode/vsce package
code --install-extension sigma-icons-*.vsix

Other editors can use the TextMate grammar in syntaxes/sigma.tmLanguage.json, which works with Sublime Text, Zed, JetBrains IDEs (through the TextMate bundles plugin) and most editors that read TextMate grammars.

Updating

cd Sigma
git pull
./build.sh
./build.sh install
sig clean

sig clean clears the compile cache so every program is rebuilt with the new version.

Uninstalling

sudo rm /usr/local/bin/sig
rm -rf ~/.cache/sigma

Troubleshooting

"couldn't run the C compiler"

Sigma needs cc, clang or gcc on your PATH. Install one with the commands above. To use a specific compiler, set SIGMA_CC:

SIGMA_CC=gcc-14 sig app.sgm

"command not found: sig"

The folder you installed to isn't on your PATH. Run ./build.sh install again and note the folder it prints, or call it with the full path, like ~/Sigma/build/sig.

The first run is slow

The first time you run a program, Sigma compiles it with the C compiler, which takes about a second. After that, it runs straight from the cache in ~/.cache/sigma until you change the code.
