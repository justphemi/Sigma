Lists

Ordered collections of values. A list can hold any mix of values, including other lists and maps.

Creating and reading

nums: [10, 20, 30]
empty: []
mixed: [1, "two", [3], {four: 4}]

yap(nums[0], nums[-1], len(nums), len(empty))

10 30 3 0

Positions start at 0. Negative positions count from the end. Reading past the end is an error that tells you the list's length. If you'd rather get a default, use get:

nums: [10, 20, 30]
yap(nums.get(5, "none"))

none

Changing a list

queue: ["a", "b"]
queue.push("c")          -- add to the end
queue.insert(0, "start") -- add at a position
queue[1]: "A"            -- replace an item
last: queue.pop()        -- remove and give back the last item
first: queue.del(0)      -- remove and give back the item at a position
yap(queue, last, first)

["A", "b"] c start

clear() empties a list. All of these change the list in place.

Lists are shared, not copied

Assigning a list to another variable, or passing it to a function, shares the same list. Changes through one name are visible through the other. Use copy() when you need an independent list.

a: [1, 2]
b: a
c: a.copy()
b.push(3)
yap(a, c)

[1, 2, 3] [1, 2]

Searching

fruits: ["apple", "mango", "pear"]
yap(fruits.has("mango"), fruits.find("pear"), fruits.find("kiwi"))

true 2 -1

Transforming

These give back a new list and leave the original alone:

nums: [4, 1, 3, 2]
yap(nums.map(n => n * n))
yap(nums.filter(n => n > 1))
yap(nums.sort())
yap(nums.sort("desc"))
yap(nums.reverse())
yap(nums.slice(1, 3))
yap(nums + [9])
yap(nums)

[16, 1, 9, 4]
[4, 3, 2]
[1, 2, 3, 4]
[4, 3, 2, 1]
[2, 3, 1, 4]
[1, 3]
[4, 1, 3, 2, 9]
[4, 1, 3, 2]

map, filter and each can also take the position as a second parameter:

yap(["a", "b", "c"].map((x, i) => "{i}={x}"))

["0=a", "1=b", "2=c"]

Sorting

sort() puts numbers in numeric order and strings in alphabetical order. Give it a function to sort by a key, and "desc" to reverse the order. Sorting is stable: items with equal keys keep their original order.

players: [
    {name: "Zara", score: 1500},
    {name: "Milo", score: 2300},
    {name: "Kai", score: 900},
]
yap(players.sort(p => p.score).map(p => p.name))
yap(players.sort(p => p.score, "desc").map(p => p.name))
yap(players.sort(p => p.name).map(p => p.name))

["Kai", "Zara", "Milo"]
["Milo", "Zara", "Kai"]
["Kai", "Milo", "Zara"]

Combining values

prices: [1200, 450, 3000]
yap(prices.sum(), min(prices), max(prices))
yap(prices.reduce((total, p) => total + p * 2, 0))
yap(["tea", "bread", "eggs"].join(", "))

4650 450 3000
9300
tea, bread, eggs

reduce(f, start) calls f(total, item) for each item, starting from start. join(sep) turns every item into text and puts sep between them.

Running code for each item

["a", "b"].each(x => yap(x))

a
b

A grind loop does the same thing and is usually clearer. each is handy at the end of a chain.

Comparing lists

== compares contents, item by item:

yap([1, [2, 3]] == [1, [2, 3]], [1, 2] == [2, 1])

true false
