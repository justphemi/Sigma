Methods

Called with a dot: list.push(x), text.upper(), map.keys(). Methods marked "in place" change the value; the others give back a new value.

List methods

MethodResult
push(x)Add x to the end. In place.
pop()Remove and give back the last item. Error if empty. In place.
insert(i, x)Put x at position i (0 to len). In place.
del(i)Remove and give back the item at i. In place.
clear()Remove everything. In place.
has(x)true if some item == x
find(x)Position of the first item == x, or -1
get(i, default?)Item at i, or default (or nil) if out of range
slice(a, b?)Items from a up to (not including) b; negative positions count from the end
map(f)New list of f(item) (or f(item, i))
filter(f)New list of items where f(item) is truthy
each(f)Call f(item) for every item
reduce(f, start)Fold: f(f(start, item0), item1) and so on
sort()Sorted copy, smallest first
sort("desc")Sorted copy, largest first
sort(key), sort(key, "desc")Sorted copy, ordered by key(item). Stable.
reverse()Reversed copy
join(sep?)Items as text with sep between (nothing between if left out)
sum()Total of the numbers (0 for an empty list)
copy()Shallow copy
xs: [3, 1, 2]
yap(xs.sort(), xs.reverse(), xs.slice(-2), xs.join("-"), xs.reduce((a, x) => a * x, 1))

[1, 2, 3] [2, 1, 3] [1, 2] 3-1-2 6

String methods

MethodResult
upper(), lower()Changed case (letters A to Z)
trim()Without whitespace at both ends
split()List of words, split on any whitespace
split(sep)List of pieces between each sep; "" splits into single bytes
replace(old, new)Every old replaced with new
has(part)true if part appears
find(part)Position of the first part, or -1
starts(p), ends(p)Starts or ends with p
slice(a, b?)Part from a up to (not including) b
repeat(n)Repeated n times
reverse()Reversed
chars()List of single characters
s: "  Hello, World  "
yap(s.trim().lower(), s.trim().split(", "), s.has("World"), s.trim().find("o"))

hello, world ["Hello", "World"] true 4

Map methods

MethodResult
keys()List of keys, in insertion order
values()List of values, in the same order
has(key)true if the key exists
get(key, default?)The value, or default (or nil) if missing
del(key)Remove the key; gives true if it was there. In place.
clear()Remove everything. In place.
copy()Shallow copy

Calling any other method name on a map calls the function stored under that key. See maps as objects.
