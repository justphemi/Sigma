Strings

Text values, how to build them and the methods for working with them.

Writing strings

Use double or single quotes. They mean the same thing, so pick whichever saves you from escaping.

a: "She said 'hi'"
b: 'He said "hey"'
yap(a)
yap(b)

She said 'hi'
He said "hey"

Interpolation

Put any expression in curly braces and its value is inserted into the string:

name: "Zara"
items: [3, 4, 5]
yap("hi {name}, you have {len(items)} items worth {items.sum() * 2} points")

hi Zara, you have 3 items worth 24 points

Lists and maps print in a readable form, and strings inside them are quoted:

player: {name: "Kai", tags: ["fast", "new"]}
yap("player: {player}")

player: {name: "Kai", tags: ["fast", "new"]}

Joining and comparing

+ joins strings. If one side is a string, the other side is converted to text.

yap("level " + 5)
yap("abc" == "abc", "apple" < "banana")

level 5
true true

Building a long string with += in a loop is fast: Sigma appends in place instead of copying the whole string each time.

Length, indexing and slicing

word: "sigma"
yap(len(word), word[0], word[-1], word.slice(1, 3), word.slice(2))

5 s a ig gma

Negative indexes count from the end, so word[-1] is the last character. slice(start, end) includes start and stops before end.

Strings are bytes

Length and indexing count bytes, not characters. Plain English text is one byte per character, but accented letters and symbols take more: len("é") is 2. Printing, joining, splitting and searching all work correctly with any text.

String methods

Methods never change the original string; they give back a new one.

Converting

yap(str(42) + "!", num("3.5") * 2, int("42"), int(9.99), num("nope"))

42! 7 42 9 nil

num and int return nil for text that isn't a number, so you can validate input with them. int drops the fractional part; use round to round to the nearest whole number.
