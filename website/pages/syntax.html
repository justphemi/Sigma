String escapes

\n new line, \t tab, \r carriage return, \0 zero byte, \\ backslash, \" and \' quotes, \{ and \} literal braces.

Comments

-- to the end of the line. A line containing only --- starts a block comment, and the next such line ends it.

Truthiness

Falsy: false, nil, 0, "", [], {}. Everything else is truthy.

Line rules

  • Newlines end statements, except inside ( ), [ ] and map literals.
  • A binary operator must be on the same line as its left operand.
  • A line may start with .method() to continue a chain from the line above.
  • nah may start on the line after a closing }.
