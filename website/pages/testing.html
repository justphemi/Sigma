Testing

Sigma doesn't need a test framework. vibecheck, a small script and your shell are enough.

Tests with vibecheck

A test file yoinks the code under test and checks results with vibecheck(condition, message). If any check fails, the file stops with an error and a non-zero exit status.

-- lib/textx.sgm
cook slugify(title) {
    words: title.lower().replace("-", " ").split()
    serve words.join("-")
}

cook initials(name) {
    serve name.split().map(w => w[0].upper()).join("")
}

-- test_textx.sgm
yoink "lib/textx.sgm"

cook expect(got, want) {
    vibecheck(got == want, "expected {want}, got {got}")
}

expect(slugify("Hello World"), "hello-world")
expect(slugify("  Sigma   is-fast "), "sigma-is-fast")
expect(initials("ada lovelace"), "AL")
expect(initials(""), "")

yap("textx: all tests passed")

textx: all tests passed

When something breaks, the error says what and where:

error: vibe check failed: expected hello-world, got hello--world
  --> tests/test_textx.sgm:5

The line points at the vibecheck inside expect. To see which call failed, put the input in the message, or call vibecheck directly in each test.

Testing errors

Check that bad input raises an error with yolo:

cook parse_age(text) {
    n: int(text)
    fr n == nil or n < 0 { yeet "bad age: {text}" }
    serve n
}

failed: false
yolo { parse_age("-4") } oops e { failed: true }
vibecheck(failed, "parse_age should reject negative ages")
yap("ok")

ok

A test runner

Save this as tests/run.sh. It runs every test_*.sgm file and reports the totals:

#!/bin/sh
cd "$(dirname "$0")" || exit 1
pass=0
fail=0
for t in test_*.sgm; do
    if sig "$t" > /dev/null 2> /tmp/sigma-test-err; then
        pass=$((pass + 1))
    else
        fail=$((fail + 1))
        echo "FAIL $t"
        cat /tmp/sigma-test-err
    fi
done
echo "$pass passed, $fail failed"
[ "$fail" -eq 0 ]

sh tests/run.sh

Because tests are cached like any program, running the suite again after a small change only recompiles the files that changed.

Expected-output tests

For programs that print a lot, compare the whole output with a saved file. Sigma's own test suite works this way.

# save the output once you've checked it by eye
sig main.sgm data/sample.txt > tests/sample.expected

# later, compare
sig main.sgm data/sample.txt | diff tests/sample.expected - && echo same

Checking without running

sig check finds compile errors in a file and everything it yoinks, without running anything. It's fast enough to run on every save from your editor, or as a git pre-commit hook:

sig check main.sgm

Running tests on GitHub

This workflow installs Sigma and runs your tests on every push. Save it as .github/workflows/test.yml:

name: test
on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Install Sigma
        run: |
          git clone --depth 1 https://github.com/justphemi/Sigma.git /tmp/sigma
          cd /tmp/sigma && ./build.sh && sudo cp build/sig /usr/local/bin/
      - name: Check
        run: sig check main.sgm
      - name: Test
        run: sh tests/run.sh
