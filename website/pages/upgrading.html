Upgrading from 0.1

Sigma 0.2 replaced the $ keywords and :: with a shorter syntax. The compiler recognises the old forms and tells you what to write instead, so upgrading is mostly following the error messages.

Bugs fixed in 0.2

  • Reassigning a variable inside a loop (total: total + i) used to create a new variable, so totals stayed at 0.
  • % didn't parse.
  • $fixed constants failed to compile.
  • try and catch never caught anything.
  • sig --version didn't work.

New in 0.2

  • Type inference, making number-heavy code as fast as C
  • String interpolation, single-quoted strings and escapes
  • Lambdas and closures
  • Maps with string keys, plus around 30 methods on lists, strings and maps
  • yoink for multi-file programs
  • Files, arguments, time and random numbers
  • Catchable runtime errors with line numbers
  • Compile errors with hints and "did you mean" suggestions
  • sig build, sig check, sig emit, the compile cache and #! scripts
